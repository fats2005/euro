# EuroRoad Racer

Modern pseudo-3D highway racing prototype built with Python + Pygame.

## Controls
W/Up accelerate, S/Down brake, A/D steer, P pause, R restart, ESC exit.

## Build Windows EXE
On Windows with Python installed, double-click `build_exe.bat`. The executable will be created at `dist\EuroRoadRacer.exe`.

This is a source project rather than a full Euro Truck Simulator clone. It uses original procedural graphics and does not include copyrighted game assets.
